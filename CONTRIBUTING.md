# Contributing to Eval Infrastructure for Agent Systems

This is a living handbook. Contributions are welcome.

## How to contribute

### Reporting errors

If you find a factual error, a code bug, or a broken link, please open an issue with:
- The chapter or file name
- The specific error
- A suggested fix (if you have one)

### Contributing a chapter

If you want to contribute a new chapter or expand an existing one:
1. Open an issue describing what you want to add
2. Fork the repo
3. Write the chapter following the existing format (8-10 minute read, code examples, production-proven)
4. Open a PR

### Contributing a notebook

If you want to add a companion notebook:
1. Follow the structure of existing notebooks
2. Use mock providers if you cannot include real API calls
3. Ensure the notebook runs top-to-bottom without errors
4. Open a PR

## Style guide

- Write in second person ("you") for directness
- Use real production examples where possible (anonymized)
- Code examples should be Python 3.11+
- Keep chapters to 8-10 minute reads (1,500-2,500 words)
- Use tables for comparisons
- Use code blocks for all code, even one-liners

## Attribution

All contributions will be attributed in the chapter's author byline and in the CONTRIBUTORS.md file.
